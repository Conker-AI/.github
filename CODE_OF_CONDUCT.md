# Code of conduct

Conker is a small project. Everyone who takes part in it (issues, pull requests, reviews and
discussions) is expected to:

- be kind and assume good intent;
- criticise ideas and code, never people;
- accept that the maintainer decides, and that "no" or "not now" is a normal answer;
- keep other people's private information private, including anything from their Conker data.

Not accepted: harassment, insults, sexualised language or images, threats, and publishing someone's
private information. This applies everywhere the project is, and to anyone speaking for it.

## Reporting

Use GitHub's **Report content** on the comment or issue, or report it privately through
**Security → Report a vulnerability** on the repository where it happened, if it needs to stay
private. Reports are read by the maintainer and kept confidential.

The maintainer may edit or remove content, and warn, block or ban anyone who breaks these rules,
for as long as needed.

This code is based on the ideas of the [Contributor Covenant](https://www.contributor-covenant.org/),
shortened for a one-person project.
